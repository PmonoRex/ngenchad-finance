การบันทึกและโหลดข้อมูลยังต้องใช้อินเทอร์เน็ต เพราะข้อมูลอยู่ใน Supabase เวอร์ชันนี้ไม่เก็บข้อมูลการเงินไว้ในแคชออฟไลน์

## ใช้งานได้แล้ว

- Dashboard จากข้อมูลจริง: ยอดรวมบัญชี, รายรับสุทธิ, รายจ่าย, เงินคงเหลือจากรายการ, กราฟรายเดือน, รายจ่ายตามหมวด, ที่มารายรับ และรายการล่าสุด
- เลือกดูย้อนหลัง 3, 6 หรือ 12 เดือน และแยก THB/USD โดยไม่แปลงค่าเงินหรือรวมสองสกุลเป็นยอดเดียว
- บันทึกรายรับ รายจ่าย และเงินโอนระหว่างบัญชี พร้อมยอดก่อนหักภาษีและภาษีหัก ณ ที่จ่ายของรายรับ
- เพิ่มบัญชีและหมวด, ค้นหา/กรองรายการ, แก้ไข, ลบแบบกู้คืน, รายการโปรด และโน้ต
- พอร์ตหุ้นไทยและสหรัฐ: บันทึกซื้อ–ขายและค่าธรรมเนียม, ดูจำนวนหุ้นและต้นทุนเฉลี่ยถ่วงน้ำหนัก, กำไรจากการขาย, มูลค่าและกำไรที่ยังไม่ขายจากราคาอ้างอิงที่กรอกเอง
- ยกเลิกและกู้คืนรายการหุ้นได้ โดยฐานข้อมูลป้องกันประวัติที่ขายเกินจำนวนหุ้นที่ถือ แม้เป็นรายการย้อนหลัง
- ประมาณการภาษีปี 2568/2569 จากเงินเดือน งานเสริม และปันผลที่บันทึกจริง พร้อมรายได้คาดการณ์ ค่าใช้จ่าย ค่าลดหย่อนที่ผู้ใช้ตรวจสิทธิ์แล้ว ภาษีหัก ณ ที่จ่าย และรายการข้อมูลที่ยังขาด
- กราฟ TradingView สำหรับหุ้นสหรัฐเมื่อกดดูด้วยรหัสตลาด:หุ้นที่ถูกต้อง; หุ้นไทยมีลิงก์เปิดกราฟรายตัวบน TradingView

Dashboard คำนวณจากรายการที่ยังไม่ถูกลบ และไม่นับเงินโอนเป็นรายรับหรือรายจ่าย ยอดรวมบัญชีเป็นยอดปัจจุบันของบัญชีสกุลที่เลือก ส่วนตัวเลขรายรับ/รายจ่ายเป็นผลรวมในช่วงเวลาที่เลือก

พอร์ตแยก THB/USD ไม่รวมข้ามสกุลเงิน ราคาหุ้นเป็นตัวเลขที่ผู้ใช้กรอกและระบุวันที่เอง จึงไม่ใช่ราคาตลาดสด รายการซื้อ–ขายในพอร์ตยังไม่ปรับยอดบัญชีเงินอัตโนมัติ หากต้องการสะท้อนเงินสดให้บันทึกในหน้ารายการเงินด้วย แต่ยอดซื้อหุ้นไม่ควรจัดเป็นรายจ่ายเพื่อการบริโภคหรือใช้ตีความรายได้/ภาษีโดยตรง ตัวเลขต้นทุนพอร์ตใช้ติดตามส่วนตัว ไม่ใช่ฐานต้นทุนเพื่อยื่นภาษี

## ภาษีและกราฟ

หน้าภาษีใช้สูตรพื้นฐานของภาษีเงินได้บุคคลธรรมดาไทย: ค่าใช้จ่ายเงินเดือนและเงินได้ ม.40(2) รวมกัน 50% ไม่เกิน 100,000 บาท, ค่าลดหย่อนส่วนตัว 60,000 บาท, อัตราขั้นบันได และวิธี 0.5% สำหรับรายได้ที่ไม่ใช่เงินเดือนเมื่อเข้าเกณฑ์ ข้อมูลปี 2569 เป็นประมาณการตามหลักเกณฑ์ที่ตรวจ ณ 25 กันยายน 2569 ไม่ใช่ผลคำนวณสำหรับยื่นแบบจริง

หากมีงานเสริม ผู้ใช้ต้องเลือกประเภท ม.40(2) หรือระบุค่าใช้จ่ายที่ตรวจสิทธิ์แล้วสำหรับเงินได้ประเภทอื่น หากมีปันผล ระบบประมาณการรวมได้เฉพาะกรณียืนยันว่าเป็นปันผลไทยที่เลือกภาษีหัก ณ ที่จ่าย 10% เป็นที่สุดและบันทึกยอดหักครบ กรณีปันผลต่างประเทศ การรวมปันผลเพื่อใช้เครดิตภาษี รายรับ USD หรือรายรับประเภทอื่น จะแสดงข้อมูลที่ขาดและไม่สรุปยอดภาษีทั้งปี ค่าลดหย่อนอื่นต้องกรอกเอง; ภาษีหัก ณ ที่จ่ายของรายได้คาดการณ์ยังไม่รวม

กราฟ TradingView โหลดเมื่อกดดูเท่านั้น รหัสของหุ้นสหรัฐต้องระบุตลาดที่ถูกต้อง เช่น `NASDAQ:AAPL` หรือ `NYSE:IBM` ตัวเลือกในพอร์ตเริ่มต้นด้วย NASDAQ เพื่อช่วยกรอก แต่ต้องตรวจแก้สำหรับหุ้นในตลาดอื่น Widget ไม่ใช่ API ราคา และไม่อัปเดตมูลค่าพอร์ตอัตโนมัติ TradingView ยังไม่ระบุ SET ในรายชื่อตลาดที่ให้ใช้กับ Widget เว็บภายนอก จึงเปิดกราฟหุ้นไทยบนเว็บไซต์ TradingView แทน

## นำเข้าหลักฐานซื้อ–ขาย

ในหน้าพอร์ตหุ้น เลือกรูป JPG/PNG/HEIC หรือ PDF หนึ่งหน้า ระบบใช้ Tesseract.js อ่านข้อความในเบราว์เซอร์ และแปลง HEIC/PDF ในเบราว์เซอร์ด้วย heic2any/PDF.js ตามลำดับ ไฟล์ต้นฉบับไม่ถูกส่งไปเก็บใน Supabase; ฐานข้อมูลเก็บเฉพาะข้อมูลรายการและ SHA-256 ของไฟล์เพื่อกันการนำเข้าไฟล์เดิมซ้ำ เครื่องมือ OCR และไฟล์ภาษาดาวน์โหลดจาก CDN เมื่อใช้ฟีเจอร์ครั้งแรก

รูปแบบหลักฐานที่ตรวจเพื่อบันทึกอัตโนมัติในรุ่นนี้คือ Dime! เมื่ออ่านตลาด ประเภทคำสั่ง หุ้น วันที่ จำนวน ราคา ค่าคอมมิชชั่น VAT และมูลค่าหุ้นครบ และจำนวนคูณราคาตรงกับยอดเอกสาร กรณีอ่านไม่ครบหรือเอกสารโบรกเกอร์อื่น เว็บจะแสดงแบบฟอร์มให้แก้แล้วกดบันทึก จำนวนหุ้นรองรับ 8 ตำแหน่งทศนิยม ส่วนราคาและค่าธรรมเนียมรองรับ 4 ตำแหน่ง ระบบไม่บันทึกยอดซื้อขายซ้ำในบัญชีเงินสดอัตโนมัติ

## Session 12 — สินทรัพย์รวมในหน้าภาพรวม

หน้าภาพรวมแสดงยอดเงินในบัญชีและมูลค่าหุ้นที่ถือแยก THB/USD พร้อมยอดรวมประมาณการเป็น THB โดยดึงอัตรา USD/THB ล่าสุดจาก Frankfurter และใช้ ExchangeRate-API แบบเปิดเป็นแหล่งสำรอง ทั้งสองแหล่งไม่ต้องใช้ API key และจะแสดงวันที่อัตราที่ใช้ หากโหลดอัตราไม่ได้ เว็บแสดงยอดแยกสกุลเงินและไม่แสดงยอดรวมบาท หุ้นที่ไม่มีราคาอ้างอิงจะไม่ถูกนำมารวม พร้อมแจ้งจำนวนรายการที่ขาดราคา

รายการซื้อ–ขายหุ้นยังไม่ปรับยอดบัญชีเงินอัตโนมัติ หากยอดบัญชีไม่ได้หักเงินซื้อหุ้นไว้ ยอดรวมสินทรัพย์อาจนับซ้ำ จึงแสดงคำเตือนบนหน้าภาพรวม
