# เงินชัด — เว็บการเงินส่วนตัว (Session 6)

เว็บออนไลน์: https://pmonorex.github.io/ngenchad-finance/  
โค้ดเว็บ: https://github.com/PmonoRex/ngenchad-finance

เปิดเว็บและเข้าสู่ระบบด้วยบัญชี Supabase ที่สร้างไว้แล้ว GitHub Pages ใช้โฮสต์เฉพาะหน้าเว็บ ส่วนบัญชีผู้ใช้และข้อมูลการเงินอยู่ใน Supabase และจำกัดการอ่าน/เขียนตามเจ้าของด้วย Row Level Security (RLS) ไม่ควรใส่ secret key หรือ `service_role` ลงในไฟล์หน้าเว็บ

## เพิ่มเป็นแอปบน iPhone

1. เปิดเว็บออนไลน์ด้วย Safari บน iPhone
2. แตะเมนูหน้าเว็บหรือปุ่มแชร์ แล้วเลือก **เพิ่มไปยังหน้าจอโฮม**
3. เปิด **เปิดเป็นเว็บแอป** แล้วแตะ **เพิ่ม**
4. เปิดไอคอน **เงินชัด** จากหน้าจอโฮมและเข้าสู่ระบบ หากระบบถามอีกครั้ง

การบันทึกและโหลดข้อมูลยังต้องใช้อินเทอร์เน็ต เพราะข้อมูลอยู่ใน Supabase เวอร์ชันนี้ไม่เก็บข้อมูลการเงินไว้ในแคชออฟไลน์

## ใช้งานได้แล้ว

- Dashboard จากข้อมูลจริง: ยอดรวมบัญชี, รายรับสุทธิ, รายจ่าย, เงินคงเหลือจากรายการ, กราฟรายเดือน, รายจ่ายตามหมวด, ที่มารายรับ และรายการล่าสุด
- เลือกดูย้อนหลัง 3, 6 หรือ 12 เดือน และแยก THB/USD โดยไม่แปลงค่าเงินหรือรวมสองสกุลเป็นยอดเดียว
- บันทึกรายรับ รายจ่าย และเงินโอนระหว่างบัญชี พร้อมยอดก่อนหักภาษีและภาษีหัก ณ ที่จ่ายของรายรับ
- เพิ่มบัญชีและหมวด, ค้นหา/กรองรายการ, แก้ไข, ลบแบบกู้คืน, รายการโปรด และโน้ต

Dashboard คำนวณจากรายการที่ยังไม่ถูกลบ และไม่นับเงินโอนเป็นรายรับหรือรายจ่าย ยอดรวมบัญชีเป็นยอดปัจจุบันของบัญชีสกุลที่เลือก ส่วนตัวเลขรายรับ/รายจ่ายเป็นผลรวมในช่วงเวลาที่เลือก

## การติดตั้งฐานข้อมูล

โปรเจกต์ Supabase นี้ติดตั้ง `supabase/001_initial.sql` และ `supabase/003_session4.sql` แล้ว ไฟล์ `supabase/002_verify.sql` ใช้ตรวจสิทธิ์และโครงสร้างเท่านั้น Session 6 ไม่ต้องเปลี่ยนฐานข้อมูล

## การเผยแพร่เวอร์ชันต่อไป

GitHub Pages เผยแพร่จาก branch `main` ที่โฟลเดอร์ root ของ repository หากแก้ไฟล์ในเครื่อง ต้องอัปเดตไฟล์ที่ชื่อเดียวกันใน repository ด้วย จึงจะเห็นเวอร์ชันใหม่บนลิงก์ออนไลน์ โปรเจกต์นี้ยังไม่ได้เชื่อม Git remote ในเครื่อง จึงอัปโหลดผ่านหน้า GitHub

## สิ่งที่ยังไม่ทำ

Dashboard ยังไม่ใช่การคำนวณภาษีทั้งปี ตัวเลขภาษีที่แสดงเป็นเพียงยอดหัก ณ ที่จ่ายตามรายการที่บันทึกไว้ พอร์ตหุ้นและกราฟ TradingView จะอยู่ใน Session ต่อ ๆ ไป
